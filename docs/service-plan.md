# 《철학자의 방》 서비스 기획안

v0.2 · 2026년 10월 12일 · 10월 11일 팀 회의 반영

## 1. 서비스 소개

**하나의 고민, 네 가지 관점.** 철학 사상에 기반한 AI 캐릭터와 대화하며 자신의 고민과 선택 기준을 탐색하는 웹 서비스다.

진로·관계·비교·일상의 선택을 다른 관점으로 살펴보고 싶은 사용자를 대상으로 한다. 철학 지식 없이도 쉽게 대화할 수 있도록 구성한다. 정답을 대신 결정하기보다 사용자가 자신의 생각을 돌아보도록 돕는다.

## 2. 서비스 특징과 철학자

한 대화방에서 철학자를 바꾸며 같은 고민을 이어간다. 기존 대화는 유지하고 메시지마다 답변한 철학자를 표시한다. 철학자마다 말투뿐 아니라 질문과 해석의 관점을 다르게 설계한다.

| 철학자 | 대화의 관점 | 포인트 색 |
| --- | --- | --- |
| 에라스무스 | 풍자와 재치로 당연한 관습과 기준을 돌아보기 | 라임 옐로 |
| 쇼펜하우어 | 욕망과 기대가 만드는 부담을 살펴보기 | 모브 |
| 니체 | 남의 기준과 내가 선택한 가치를 구분하기 | 블루 |
| 에픽테토스 | 통제할 수 있는 것과 오늘의 행동을 찾기 | 청록 |

철학자 AI 대화 서비스는 이미 존재하는 유형이다. 본 프로젝트는 한국어 일상 고민과 같은 대화를 유지하며 관점을 바꾸는 경험에 집중한다. 경쟁 서비스에 없는 기능이라는 주장은 하지 않는다.

## 3. 핵심 기능과 이용 흐름

- 회원가입, 이메일 인증, 로그인
- 철학자 소개 조회 및 선택
- AI와 텍스트 대화, 같은 대화방에서 철학자 전환
- 대화 기록 저장 및 본인의 지난 대화 조회·삭제
- 답변 대기·오류 안내 및 입력 검증

**이용 흐름:** 메인에서 소개 확인 → 로그인 → 철학자 선택 → 채팅 화면 → 첫 메시지 전송으로 대화 시작 → 필요하면 철학자 전환 → 지난 대화 다시 열기.

소개는 비로그인 상태에서도 볼 수 있다. 비로그인 사용자가 대화를 시작하면 로그인 화면으로 이동한다. 가입 후 이메일 인증을 완료해야 로그인할 수 있으며, 로그인 성공 후 메인으로 돌아간다.

예를 들어 ‘해야 할 일이 많아 불안하다’는 고민을 니체와 이야기하며 자신의 기준을 살펴본 뒤, 에픽테토스로 전환해 오늘 할 수 있는 행동을 찾는다.

## 4. 화면 구성

| 화면 | 주요 내용과 동작 |
| --- | --- |
| 메인·철학자 소개 | 네 철학자의 초상·소개·대화 버튼. 비로그인 상태에는 로그인 버튼 표시 |
| 로그인 | 로그인 입력과 회원가입 버튼. 성공 후 메인으로 이동 |
| 회원가입 | 가입 완료 후 로그인 화면으로 이동하며 이메일 인증 안내 |
| 이메일 인증 결과 | 성공·실패 표시. 성공 시 로그인 버튼, 실패 시 잘못된 링크 안내 |
| 채팅 | 현재 철학자, 대화 내역, 메시지 입력·전송, 철학자 전환 |

지난 대화 목록의 배치와 철학자 전환 버튼의 위치는 디자인 과정에서 확인한다.

## 5. 디자인 및 개발 방향

밝은 페이지 배경과 어두운 선드로잉 초상을 조합한다. 철학자 소개와 채팅 영역은 배경·경계·간격으로 구분한다. 초상 뒤 원의 색을 대화 화면의 이름과 포인트 색에도 이어 사용한다.

- **프론트엔드:** React·TypeScript·Vite, shadcn/ui, pnpm
- **백엔드:** FastAPI, 사용자 인증, AI API 연동
- **데이터:** 팀 DB 구조와 API 명세에 따라 사용자·철학자·채팅·메시지 처리
- **실행 환경:** Docker Compose로 앱과 DB 구성. DB는 기존 이미지 사용, 데이터는 볼륨에 보존
- **협업:** GitHub Flow, 기능 브랜치와 PR, 팀원별 유의미한 커밋 10회 이상

프론트는 백엔드 API로 철학자 소개를 받아온다. 첫 메시지 전송 시 대화 생성과 메시지 전송을 연결하는 세부 순서는 API 명세에 맞춰 구현한다. API 키는 백엔드에서 관리하며 사용자는 본인의 기록만 접근한다.

## 6. 진행 계획과 AI 응답 원칙

태린은 **10월 13일 화요일까지 기본 화면 디자인을 공유**하고 React 기초를 학습한다. 시안 확인 후 구현할 컴포넌트와 API 연결 범위를 팀에서 세부 분담한다. 백엔드·인증·DB·Docker 작업은 각 담당 영역에서 진행한다.

AI는 실제 철학자가 아닌 사상 기반 캐릭터임을 안내한다. 쉬운 한국어로 대화하고 사용자의 결정을 대신하거나 검증되지 않은 문장을 실제 명언처럼 제시하지 않는다. 상세 AI 프롬프트는 개발 문서에서 별도로 관리한다.

첫 버전은 텍스트 대화와 인증·기록·철학자 전환에 집중한다. 음성, 철학자 간 자동 토론 등 확장 기능은 후속 검토한다.
